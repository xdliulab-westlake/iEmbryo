# ViT-Hybrid 模型架构详细说明

## 1. 整体模型结构

```
输入: (batch_size, 33, 11, 3, 224, 224)
      ↓
┌─────────────────────────────────────────────────────┐
│ VGG16 特征提取器 (冻结)                             │
│ - 处理每张图像: (3, 224, 224) → (512,)             │
│ - 输出: (batch*33*11, 512)                         │
└─────────────────────────────────────────────────────┘
      ↓
重塑为 (batch, 33, 11, 512)
      ↓
┌─────────────────────────────────────────────────────┐
│ 焦平面融合 (Focal Plane Fusion)                     │
│ - 对每个时间点的11个焦平面进行融合                  │
│ - 输出: (batch, 33, 512)                           │
└─────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────┐
│ 位置编码 (Positional Encoding)                      │
│ - 添加可学习的位置编码信息                          │
│ - 输出: (batch, 33, 512)                           │
└─────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────┐
│ Transformer 编码器 (4层)                            │
│ - 处理时间序列的全局动态模式                        │
│ - 输出: (batch, 33, 512)                           │
└─────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────┐
│ 全局平均池化 (Global Average Pooling)               │
│ - 沿时间维度求平均                                 │
│ - 输出: (batch, 512)                               │
└─────────────────────────────────────────────────────┘
      ↓
┌─────────────────────────────────────────────────────┐
│ 分类头 (Classification Head)                        │
│ - Dense(512 → 256, ReLU)                           │
│ - Dropout(0.3)                                     │
│ - Dense(256 → 1, Sigmoid)                          │
│ - 输出: (batch, 1) ∈ [0, 1]                        │
└─────────────────────────────────────────────────────┘
      ↓
输出: 胚胎质量概率
```

---

## 2. 详细模块说明

### 2.1 VGG16 特征提取器 (VGG16FeatureExtractor)

**输入输出：**
- 输入: (batch, 3, 224, 224) - 单张RGB图像
- 输出: (batch, 512) - 512维特征向量

**架构：**
```python
VGG16(pretrained=True)
  ├─ features (13层卷积网络)
  │  ├─ Conv2d(3, 64, kernel_size=3)
  │  ├─ MaxPool2d(kernel_size=2)
  │  ├─ Conv2d(64, 128, kernel_size=3)
  │  ├─ MaxPool2d(kernel_size=2)
  │  ├─ Conv2d(128, 256, kernel_size=3)
  │  ├─ MaxPool2d(kernel_size=2)
  │  ├─ Conv2d(256, 512, kernel_size=3)
  │  ├─ MaxPool2d(kernel_size=2)
  │  ├─ Conv2d(512, 512, kernel_size=3)
  │  └─ MaxPool2d(kernel_size=2)
  │
  ├─ avgpool: AdaptiveAvgPool2d((7, 7))
  │  └─ 输出: (batch, 512, 7, 7)
  │
  └─ classifier: 全连接层
     ├─ Linear(512*7*7=25088 → 4096)
     ├─ ReLU()
     ├─ Dropout()
     ├─ Linear(4096 → 512)
     └─ ReLU()
```

**参数：**
- 总参数: ~138M (大部分来自ImageNet预训练)
- 冻结状态: Stage 1 冻结，Stage 2 解冻后4层

**特点：**
- 使用ImageNet预训练权重
- 捕捉空间纹理、边缘、形状等低中高层特征
- 两阶段训练: 第一阶段冻结以保持预训练知识

---

### 2.2 焦平面融合 (FocalPlaneFusion)

**输入输出：**
- 输入: (batch, 11, 512) - 11个焦平面的特征
- 输出: (batch, 512) - 融合后的单个特征向量

**架构：**
```
11个焦平面特征 (batch, 11, 512)
  │
  ├─ 焦平面0: (batch, 512)
  ├─ 焦平面1: (batch, 512)
  ├─ ...
  └─ 焦平面10: (batch, 512)
  │
  ▼
平均融合 (Mean Pooling along dim=1)
  │
  ▼
融合特征 (batch, 512)
```

**融合策略：**
- **Average Fusion** (默认): `output = mean(focal_planes, dim=1)`
  - 保留所有焦平面的信息
  - 避免对特定焦平面的偏差
  - 更稳定的特征表达

- **Max Fusion** (可选): `output = max(focal_planes, dim=1)[0]`
  - 保留最显著的焦平面特征
  - 对异常值不敏感

---

### 2.3 位置编码 (PositionalEncoding)

**输入输出：**
- 输入: (batch, 33, 512) - 时间序列特征
- 输出: (batch, 33, 512) - 加入位置信息的特征

**架构：**
```python
self.pos_encoding = nn.Parameter(torch.randn(1, 33, 512))
output = input + pos_encoding
```

**特点：**
- **可学习的位置编码** (不是固定的sin/cos编码)
- 显式建模时间顺序信息
- 33个时间点, 每个都有独立的512维位置向量
- 参数总数: 1 × 33 × 512 = 16,896

---

### 2.4 Transformer 编码器块 (TransformerBlock)

**输入输出：**
- 输入: (batch, 33, 512) - 33个时间步的特征序列
- 输出: (batch, 33, 512) - 编码后的特征序列

**单个块的架构：**
```
输入: (batch, 33, 512)
  │
  ├─ 多头自注意力 (MultiheadAttention)
  │  ├─ Query: (batch, 33, 512)
  │  ├─ Key: (batch, 33, 512)
  │  ├─ Value: (batch, 33, 512)
  │  ├─ num_heads: 8
  │  ├─ head_dim: 512/8 = 64
  │  └─ 输出: (batch, 33, 512)
  │
  ├─ Dropout(0.1)
  │
  ├─ 残差连接 + LayerNorm
  │  └─ output = LayerNorm(input + attention_output)
  │
  ├─ 前馈网络 (FFN)
  │  ├─ Linear(512 → 1024) + ReLU
  │  ├─ Dropout(0.1)
  │  └─ Linear(1024 → 512)
  │
  ├─ Dropout(0.1)
  │
  ├─ 残差连接 + LayerNorm
  │  └─ output = LayerNorm(input + ffn_output)
  │
  └─ 输出: (batch, 33, 512)
```

**多头自注意力机制详解：**
```
输入: (batch, 33, 512)
  │
  ├─ 线性投影到8个头
  │  └─ 每个头: (batch, 33, 64)
  │
  ├─ 计算注意力权重
  │  ├─ Q·K^T / √d_k  (where d_k=64)
  │  ├─ 形状: (batch, 33, 33)
  │  ├─ 表示时间步之间的相关性
  │  └─ softmax + dropout
  │
  ├─ 应用到Value
  │  └─ attention_weights · V
  │
  ├─ 合并8个头
  │  └─ 拼接后投影: (batch, 33, 512)
  │
  └─ 输出: (batch, 33, 512)
```

**前馈网络：**
```
输入: (batch, 33, 512)
  │
  ├─ Dense: 512 → 1024 (扩展)
  ├─ ReLU激活
  ├─ Dropout(0.1)
  ├─ Dense: 1024 → 512 (压缩)
  │
  └─ 输出: (batch, 33, 512)
```

**4层Transformer的数据流：**
```
Block1: (batch, 33, 512) → (batch, 33, 512)
  │
Block2: (batch, 33, 512) → (batch, 33, 512)
  │
Block3: (batch, 33, 512) → (batch, 33, 512)
  │
Block4: (batch, 33, 512) → (batch, 33, 512)
```

---

### 2.5 全局平均池化 (Global Average Pooling)

**输入输出：**
- 输入: (batch, 33, 512) - Transformer输出
- 输出: (batch, 512) - 全局特征向量

**操作：**
```python
output = torch.mean(input, dim=1)  # 沿时间维度求平均
```

---

### 2.6 分类头 (Classification Head)

**输入输出：**
- 输入: (batch, 512) - 全局特征
- 输出: (batch, 1) - 胚胎质量概率 ∈ [0, 1]

**架构：**
```
输入: (batch, 512)
  │
  ├─ Dense层: 512 → 256
  ├─ ReLU激活
  ├─ Dropout(0.3) ← 较高的dropout防止过拟合
  │
  ├─ Dense层: 256 → 1
  ├─ Sigmoid激活 (输出概率)
  │
  └─ 输出: (batch, 1) ∈ [0, 1]

阈值判定:
  - output > 0.5: 好胚胎 (quality=1)
  - output ≤ 0.5: 差胚胎 (quality=0)
```

## 3. 完整数据流示例

假设输入：`(batch=2, time=33, focal=11, C=3, H=224, W=224)`

```
Step 1: VGG16 特征提取
  Input: (2, 33, 11, 3, 224, 224)
  Reshape: (2*33*11, 3, 224, 224) = (726, 3, 224, 224)
  VGG16处理: (726, 3, 224, 224) → (726, 512)
  Output: (726, 512)

Step 2: 重塑
  Reshape: (2, 33, 11, 512)

Step 3: 焦平面融合
  Input: (2, 33, 11, 512)
  对每个时间点融合11个焦平面:
    t=0: (2, 11, 512) → (2, 512)
    t=1: (2, 11, 512) → (2, 512)
    ...
    t=32: (2, 11, 512) → (2, 512)
  Output: (2, 33, 512)

Step 4: 位置编码
  Input: (2, 33, 512)
  Add learnable pos_encoding: (1, 33, 512)
  Output: (2, 33, 512)

Step 5: Transformer块 (4层)
  Input: (2, 33, 512)
  Block1: (2, 33, 512) → (2, 33, 512)
  Block2: (2, 33, 512) → (2, 33, 512)
  Block3: (2, 33, 512) → (2, 33, 512)
  Block4: (2, 33, 512) → (2, 33, 512)
  Output: (2, 33, 512)

Step 6: 全局平均池化
  Input: (2, 33, 512)
  Mean along time: (2, 512)

Step 7: 分类头
  Input: (2, 512)
  Dense + ReLU: (2, 256)
  Dropout: (2, 256)
  Dense + Sigmoid: (2, 1)
  Output: (2, 1) → [[0.8], [0.2]]

最终预测:
  样本1: 0.8 > 0.5 → 好胚胎
  样本2: 0.2 ≤ 0.5 → 差胚胎
```

## 4. 模型参数统计

```
VGG16特征提取器:
  - features (13层卷积): ~14.7M参数 (预训练)
  - classifier FC层: ~16.8M参数
  - 小计: ~138M参数 (大部分冻结在Stage 1)

焦平面融合: 0参数 (仅融合操作)

位置编码:
  - 可学习位置编码: 33 × 512 = 16,896参数

Transformer编码器 (4层):
  - 每层:
    - 多头注意力: 3 × 512² = 786,432参数
    - LayerNorm: 2 × 512 = 1,024参数
    - FFN: 512 × 1024 × 2 = 1,048,576参数
    - 小计/层: ~1.84M参数
  - 4层总计: ~7.36M参数

分类头:
  - FC1 (512→256): 131,328参数
  - FC2 (256→1): 257参数
  - 小计: ~131,585参数

总参数数: ~145.5M
可训练参数 (Stage 1): ~7.5M (仅Transformer + 分类头)
可训练参数 (Stage 2): ~145.5M (全部)
```

## 5. Transformer 的作用

### 为什么使用Transformer处理时间序列？

1. **全局连接性**
   - CNN: 局部感受野，需要多层堆叠才能获得全局信息
   - Transformer: 自注意力直接连接所有时间步

2. **长距离依赖建模**
   - 胚胎发育是连续过程 (0-112小时)
   - 自注意力无需长程梯度传递即可捕捉长距离依赖

3. **时间动态模式学习**
   - 胚胎质量与整个发育过程相关
   - Transformer学习：`胚胎在哪些时间点的特征变化最重要？`

4. **灵活的注意力权重**
   - 不同胚胎可能有不同的关键时间点
   - 自注意力可动态调整每个时间步的权重

## 6. 两阶段训练策略

### Stage 1: Transformer 训练 (VGG16冻结)
```
VGG16特征: 固定 (ImageNet知识)
       ↓
Transformer: 可训练 ← 学习时间序列模式
       ↓
分类头: 可训练 ← 学习判决边界
```

优点：
- 快速收敛 (只训练小部分参数)
- 保持预训练特征
- 避免小样本过拟合

### Stage 2: 联合微调 (VGG16解冻)
```
VGG16特征: 可训练 ← 微调以适应胚胎数据
       ↓
Transformer: 可训练 ← 进一步优化
       ↓
分类头: 可训练 ← 精细化
```

优点：
- 进一步提高性能
- 使VGG16特征对胚胎更适应
- 所有层联合学习最优表达

## 7. 关键设计选择

| 选项 | 当前值 | 说明 |
|------|--------|------|
| VGG16冻结方式 | 完全冻结 → 解冻后4层 | Stage1保持预训练，Stage2微调高层 |
| 焦平面融合 | Average | 保留所有焦平面信息 |
| 位置编码 | 可学习 | 比固定编码更灵活 |
| Transformer层数 | 4 | 平衡表达能力和参数量 |
| 注意力头数 | 8 | 512/8=64维头大小 |
| FFN维度 | 1024 | 512的2倍 (标准Transformer比例) |
| 分类头设计 | 512→256→1 | 梯度衰减+防过拟合 |
| 激活函数 | ReLU + Sigmoid | ReLU用于隐层，Sigmoid用于输出概率 |
