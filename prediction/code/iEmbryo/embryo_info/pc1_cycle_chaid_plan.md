# PC1 周期级 CHAID 方案（中文）

## 背景与约束
目前只有**周期/病人级**的妊娠结局（移植后妊娠结果），并不知道具体是哪 1–2 个胚胎被移植，因此**不能以胚胎为监督标签**。模型应当建立在**周期级别**。

## 目标
使用胚胎图片计算 PC1，然后汇总到周期级特征，用这些特征做 CHAID 分析，替代“Good/Poor 质量”分类。

## 特征构建策略

### 1) 胚胎层（11 个焦面 → 1 个胚胎 PC1）
- **胚胎 PC1 = 11 个焦面 PC1 的中位数（median）**
  - 抗虚焦/噪声，稳定性最好。
- 可选保留：
  - `pc1_std`：焦面之间的稳定性
  - `pc1_max`：最清晰焦面

### 2) 周期层（多个胚胎 → 1 个周期 PC1）
**推荐用于 CHAID 的指标（最终建议）**
- `pc1_median`：周期内胚胎 PC1 的中位数（最稳健）
- `pc1_p90`：周期内胚胎 PC1 的 90% 分位（体现较好胚胎）
- `n_embryos`：周期胚胎数量（信息量与选择空间）

**可选补充指标**
- `pc1_max`：周期内最大 PC1（不稳定，慎用）
- `pc1_mean`：周期均值（易受异常影响）
- `pc1_std`：胚胎间差异

> 若必须精简到最少指标：**pc1_median + pc1_p90 + n_embryos**  
> 若只能保留一个指标：**pc1_median**

## 最终 CHAID 输入结构（替换原有质量指标）
原来你用的是：`embryo quality + BMI + maternal age`。  
现在建议用 **PC1 周期特征替代 embryo quality**，其余保持不变。

**推荐版本（更稳健）**
- `pc1_median`
- `pc1_p90`
- `BMIgroup`
- `AgeGroup`
- （可选）`n_embryos`

**最精简版本（对应原先 3 变量）**
- `pc1_median`
- `BMIgroup`
- `AgeGroup`

对应的输入表示例：
| PatientID | pc1_median | pc1_p90 | BMIgroup | AgeGroup | n_embryos | Pregnancy |
|-----------|------------|---------|---------|---------|-----------|-----------|

`Pregnancy` 为周期级妊娠结局（如“临床妊娠/非临床妊娠”）。

## 下一步
1. 收集每个病人周期内所有胚胎图片。
2. 用 `unified_pca_analysis.py` 计算每张图的 PC1。
3. 焦面 → 胚胎：取中位数作为胚胎 PC1。
4. 胚胎 → 周期：计算 `pc1_median`、`pc1_p90`、`n_embryos`。
5. 用上述指标建立 CHAID。
