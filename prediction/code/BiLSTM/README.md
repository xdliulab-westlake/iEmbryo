## 主要功能

### 1. 多模型特征提取（优化版）
- EfficientNetV2-M → 降维到512维
- ResNet152V2 → 降维到512维  
- DenseNet201 → 降维到512维
- VGG16 → 保持512维，添加L2正则化
- **总特征维度：2048维（原5760维）**

### 2. BiLSTM时序建模
- 双向LSTM处理时序特征
- 多焦平面特征融合
- 回归预测BS_prime分数

### 3. 逻辑回归分类
- 基于预测分数和年龄的分类
- 特征重要性分析
- 性能评估和可视化

### 4. 交叉验证
- 5折分层交叉验证
- 模型稳定性评估
- 集成预测结果

## 输出文件

- `bilstm_quality_model.h5` - 训练好的模型
- `multi_model_analysis.pdf` - 主要分析图表
- `feature_importance.pdf` - 特征重要性图表
- `cv_analysis.pdf` - 交叉验证分析图表
- `cv_results.json` - 交叉验证结果数据

## 注意事项

1. **GPU配置**: 代码会自动检测GPU并配置最优设置
2. **内存管理**: 大特征维度时建议使用较小的批量大小
3. **数据路径**: 确保所有必需的文件路径都存在
4. **数据类型**: 所有数据都会自动转换为float32类型
5. **过拟合防护**: 使用特征降维和正则化技术减少过拟合风险

## 故障排除

### 常见问题
1. **GPU内存不足**: 减小批量大小或使用CPU训练
2. **文件路径错误**: 检查`/liaozizhuo/`目录下的文件
3. **数据类型错误**: 确保输入数据为数值类型

### 调试模式
代码包含详细的内存监控和错误日志，可以帮助诊断问题。

## 性能指标

- **MAE**: 平均绝对误差（回归性能）
- **AUC**: ROC曲线下面积（分类性能）
- **准确率**: 分类准确率
- **稳定性**: 交叉验证结果的变异系数
